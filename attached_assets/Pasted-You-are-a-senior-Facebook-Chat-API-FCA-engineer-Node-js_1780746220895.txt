# Nickname Lock System Upgrade

Enhance the nickname command.

Implement:

## User-Level Nickname Lock

When replying to a user:

* Lock that user's nickname
* Persist the lock in storage
* Restore nickname automatically if changed
* Apply only to the targeted user

Example:

/nickname lock

(replied to user)

Result:

* Only that user's nickname is protected.

---

## Group Nickname Lock

Maintain existing group-wide nickname lock functionality.

---

## Priority Rules

If a user has an individual nickname lock:

* Group nickname lock MUST NOT override it.
* User-specific lock always has higher priority.

Priority:

User Lock > Group Lock > Normal Nickname Behavior
